# Personal documents

Drop the documents the **About Me** page should answer from into this folder:

- `resume.pdf` / `resume.docx`
- `cover_letter.pdf` / `cover_letter.docx`
- any other supporting docs

Supported formats: **`.pdf`, `.docx`, `.txt`, `.md`**.

All supported files here are loaded into the model's context at page load, so keep
the contents to what you're comfortable sharing — these files are committed to the
repo and deployed with the app.
